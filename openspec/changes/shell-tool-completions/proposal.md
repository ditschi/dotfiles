# Proposal

## Why

Copilot CLI and Zellij are installed but do not currently offer tab completion in the configured shells. The shell setup should enable completion for installed command-line tools when they provide it, and new tool integrations should not leave that support behind.

## What Changes

- Audit command-line tools installed by core and feature groups, and enable their native Bash and Zsh completion generators plus completions already supplied by configured providers.
- Add generated completion support for Copilot CLI, Zellij, GitHub CLI, OpenCode, uv, mise and other generators found by the audit.
- Document tools that have upstream static completion files but are not supplied by the configured providers; do not vendor those scripts in this change.
- Keep generated completion data in the user cache, refresh it when its source tool changes, and skip absent optional tools without startup errors.
- Document completion prerequisites and skip only the dependent completion when an optional framework is unavailable.
- Add project-wide OpenSpec guidance to check for supported shell completion whenever a feature or group adds a command-line tool.
- Require the tool-management spec to include and enable supported shell completion for future tool additions.

## Capabilities

### New Capabilities

None.

### Modified Capabilities

- `user-tools`: require completion support to be considered when a feature or group adds a command-line tool.
- `zsh-plugins`: register supported tool completions after `compinit` while preserving deferred startup and the existing completion order.
- `bash-shared-config`: load supported tool completions in interactive Bash, including when Bash is used as the fallback shell.

## Impact

- Shell configuration under `home/core/.shell/` and its explicit Bash/Zsh loaders.
- `openspec/config.yaml` for guidance that applies when future OpenSpec artifacts are created.
- Specs for `user-tools`, `zsh-plugins` and `bash-shared-config`.
- Shell completion tests and startup validation. No new runtime dependency is expected; completion scripts are generated by installed tools or supplied by existing completion providers.
